# 文件导航

打开“本机文件”后，顶部始终显示返回按钮。首次选择“授权一个文件夹”时由 Android 系统决定可选位置；授权后由映汐列出内容，并显示“本机文件 › 授权文件夹 › 子文件夹”面包屑。

点击面包屑可跳到任一祖先目录，当前目录不可重复点击；长路径横向滚动。返回按钮和系统返回均逐层向上，文件夹根层回到授权列表，列表再返回原页面。移除文件夹只撤销应用授权，不删除磁盘文件。未完成的旧读取不得在返回或移除后重新写回界面。

避难所目录的面包屑可以点击返回祖先目录和协议允许的根目录；默认进入目录不会限制重新定位。返回按钮和系统返回逐层向上，在默认进入目录返回避难所列表。读取始终使用原协议、账户、共享目录和 SFTP 主机身份。

日常浏览以海报墙显示目录与视频，卡片保留实际名称，点击目录进入下一层，点击视频开始播放。选择默认目录时继续使用文件夹列表。目录标题使用当前目录名，下方保留避难所名；阿里云盘已读取的目录名会保存在本机，重启后仍可显示，移除账户时一并清理。

收藏和分组位于目录顶部的更多菜单，菜单标题与操作目标是当前文件夹。目录读取中的反馈显示在现有的项目数/刷新栏和被点击行内，不插入额外状态行；进入子目录后清除上一级选中标记。

单文件系统选择器仍可使用。它属于 Android 系统界面，应用不替换其按钮。SAF 只授权用户选定的目录；系统可能限制存储根目录、Download 根层和应用私有目录，详见 [Android 文档授权说明](https://developer.android.com/training/data-storage/shared/documents-files)。
