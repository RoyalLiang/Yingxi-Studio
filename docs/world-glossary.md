## 应用名称与故事实体分开解释

应用统一为「映汐放映站」，保留「避难所」「废墟档案库」等废土风格名称。远程媒体通过「幸存者据点」（SMB/SFTP）与「外部信号塔」（网盘/WebDAV）分别登记，「废墟档案库」指本机影像；故事中的避难所指实体聚居据点。「档案室」收录人物、性格、语录与据点大事记，章节来信在「探索」中阅读；大事记按应用版本选录变化，「相伴第 N 天」按本地首次安装日期计天。

阿汐给旧片罐补写侧签、迟灯照看设备，属于既有据点日常；地下建筑已由用户采用，路线调查仍单独记录。「封存柜」是应用内私密目录与剧集登记，不移动或加密原文件。

「今日拾获」是实际浏览目录时新记录的媒体；「信号破译中」保留「正在缓冲」的读屏说明。这些名称不代表物资掉落、文件修复、觉醒能力或章节解锁。
