# 海报和字幕的自动匹配

映汐优先使用已有媒体信息，并在后台补充海报和字幕。可以在**设置 → 海报与字幕**关闭自动查询。自动查询不影响手动载入字幕。

## 海报按来源逐级查找

1. 读取影片目录中的同名海报，例如 片名-poster.jpg、片名.jpg，以及 poster.jpg、folder.jpg、cover.jpg、poster.png、folder.png。
2. 清理文件名中的年份、分辨率和发行标记。带季集标记的剧集先查询 TVmaze；影片查询 Wikipedia 页面图片。
3. 只接受片名一致且没有明确年份冲突的匹配。无法确定时，继续显示视频帧。视频中的内嵌封面也可作为本地缩略图。

海报来自用户自己的目录或公开资料源。在线查询只发送整理后的片名和年份，不发送云盘凭据、目录地址或视频。最近播放卡片的菜单会显示在线海报的来源链接。图片版权以对应来源页为准；TVmaze 数据按其 CC BY-SA 条款使用。

缓存保存在应用私有目录，最多保留 128 张海报、48 MiB。可以在设置中清理海报缓存。删除播放记录会清除该记录的海报；清空记录会清理海报、视频帧和在线字幕缓存。权限过期或来源身份改变时，不会为了获取海报弹出授权窗口。

## 字幕按影片指纹匹配

射手公开接口采用影片四段数据的 MD5 指纹查询字幕。映汐读取四段 4096 字节的数据，发送指纹及文件名，不上传完整影片、云盘账户或服务器路径。接口无法命中重新编码或没有收录的版本时，可以手动载入字幕。

没有可用内嵌字幕、没有已加载外部字幕且未关闭字幕时，播放器会等待起播缓冲后查询一次。音字幕面板中的在线查找按钮可以主动查询。默认结合结果标记和对白内容优先选择简体中文，兼容双语；设置中可切换为双语优先。接口本身的中文筛选和字幕描述不能保证每份结果都准确标注语言。

支持 SRT、ASS/SSA 和 WebVTT，兼容 UTF-8、UTF-16、GB18030、Big5 和 gzip，应用接口返回的时间偏移。无语言标签时会检查对白中的中文、简繁特征及双语内容，降低误选英文或乱码字幕的概率；这不是完整语言识别。仅下载 HTTPS 字幕，限制响应和解压后的体积为 4 MiB；遇到无结果、服务异常或无效字幕时保留现有播放。下载结果缓存于应用私有目录，最多 64 份。切换影片会取消旧请求，避免将上一个影片的结果加载到新影片。

## 实现和验证边界

- 阿里云盘目录会话使用独立取消对象。关闭目录会话不会取消历史重播的父请求；父请求取消仍能关闭会话。
- 核心夹具验证指纹偏移、短读取、结果排序、无匹配、大小限制、字幕编码/时间轴和海报歧义。
- Android 夹具验证连续准备两次云盘历史重播、选中态尺寸不变、目录封面缓存以及实际字幕渲染和播放队列保留。
- 公开服务可达性与真实影片命中率是不同证据。合成视频的射手查询返回无匹配；公开历史指纹命中三份候选，实际适配器成功解码两份中文字幕并拒绝一份无法可靠识别编码的结果。Wikipedia 影片海报和 TVmaze 剧集海报均完成查询与下载。没有使用私人云盘凭据或用户影片库验证字幕覆盖率，也没有进行一加真机验收。

协议与资料来源：[TVmaze API](https://www.tvmaze.com/api)、[MediaWiki PageImages](https://www.mediawiki.org/wiki/API:Pageimages)、[SPlayer 开源项目](https://github.com/tomasen/splayer)。字幕协议由映汐独立实现，没有复制 SPlayer 源码。

## 匹配与缓存更新

片名匹配保留续集编号、年份和季集。Wikipedia 查询接受本次精确片名产生的规范化、简繁转换和重定向，例如“小丑2”可以解析到《小丑：雙重瘋狂》。请求允许页面的非自由海报图片，避免默认仅自由图片时挑到其他插图。只有影片页面且年份证据相符时才采用；消歧义、多候选或年份不明时保留视频帧回退。剧集在 TVmaze 未找到唯一匹配时不回退到同名电影。

带有片名的目录封面始终优先。通用 `poster.jpg`、`folder.jpg`、`cover.jpg` 及对应 PNG 仅用于目录内的视频均属于同一片名和年份的情况，避免混合电影目录串图。

海报缓存记录匹配规则版本、片名和获取时间。旧规则结果、片名改变、元数据缺失或超过 7 天的结果会重新查询。当前规则不确定时不继续保留旧海报；仍可使用视频预览帧。设置中的海报缓存清理继续可用。

“小丑2”的回归夹具来自 [Wikipedia 官方 API](https://zh.wikipedia.org/w/api.php?action=query&format=json&redirects=1&converttitles=1&titles=%E5%B0%8F%E4%B8%912&prop=pageimages%7Cpageprops%7Ccategories&pilicense=any&pithumbsize=640&cllimit=50)，采集于 2026-10-20；它验证该时点的公开资料响应，不表示已读取用户媒体目录或核对用户此前的错误图片。

返回首页或将应用切回前台时，会重试缺失的海报，已有且有效的海报继续使用缓存。旧请求在取消或刷新后不能重新写入失败结果；暂时不可读的来源可在恢复连接后再次尝试，标题与同目录海报的匹配规则仍保持一致。
