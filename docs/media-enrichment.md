# 海报、字幕与外挂音轨

映汐优先使用已有媒体信息，并在后台补充海报和字幕。可以在**设置 → 海报与字幕**关闭自动查询。自动查询不影响手动载入字幕。

## 海报按来源逐级查找

1. 读取影片目录中的同名海报，例如 片名-poster.jpg、片名.jpg，以及 poster.jpg、folder.jpg、cover.jpg、poster.png、folder.png。
2. 清理文件名中的年份、分辨率和发行标记。带季集标记的剧集先查询 TVmaze；影片查询 Wikipedia 页面图片。
3. 只接受片名一致且没有明确年份冲突的匹配。无法确定时，继续显示视频帧。视频中的内嵌封面也可作为本地缩略图。

海报来自用户自己的目录或公开资料源。在线查询只发送整理后的片名和年份，不发送云盘凭据、目录地址或视频。最近播放卡片的菜单会显示在线海报的来源链接。图片版权以对应来源页为准；TVmaze 数据按其 CC BY-SA 条款使用。

避难所的海报墙也使用同一匹配规则。剧集目录优先查看自己目录中的海报，再按目录名匹配；数字集名使用当前目录的可读名称，云盘的文件 ID 不作为剧名。可读路径提示只用于封面匹配，实际浏览和播放仍使用原文件路径，不会把目录当成视频读取。没有匹配结果时保留目录或视频图标，不为海报墙启动逐个视频的帧解码。

播放器不再在播放期间自动预热预览或提取封面，减少与主播放流争用读取和解码资源。帧预览由拖动进度的动作触发，仍使用独立读取，松手前不改变主播放位置。

海报保存在应用私有文件目录 `files/media-posters-v2`，最多保留 256 张、128 MiB；系统清理临时缓存后仍可读取。图片先落盘，再原子发布对应来源记录，避免图片与元数据错配。可以在设置中清理海报缓存。删除播放记录会清除该记录的海报；清空记录会清理海报、视频帧和在线字幕缓存。权限过期或来源身份改变时，不会为了获取海报弹出授权窗口。

## 缺少字幕时自动匹配

播放器先看内嵌与同目录字幕，没有可用字幕且用户未关闭字幕时，在起播缓冲后自动查询一次。站务中的**字幕驿站**默认选择 SubHD，也可切换射手或自定义搜寻地址。SubHD 按片名、年份和季数搜索，再核对集数；射手按影片四段数据的 MD5 指纹和文件名匹配。均不上传影片内容或 NAS 凭据。

结果结合标记与对白内容优先选择简体中文，设置中可优先双语。有效字幕接回当前影片，保留队列、暂停、位置和倍速。支持规范化 SRT、VTT、ASS/SSA；来源拒绝下载、需要网站验证或不能提供支持的文件时，在字幕面板显示真实匹配页供用户继续。SubHD 当前公开搜索可用，匿名准备下载请求拒绝，不标为网站端到端自动下载已通过。

字幕开关与来源切换会取消旧请求，封存档案不联网匹配。语种来自轨道标签或明确的文件名标记；缺失时显示“未标注语种”，不推断语音语言。实现与验证见[alpha.58 记录](track-subtitle-preview-validation.md)。

## 实现和验证边界

- 阿里云盘目录会话使用独立取消对象。关闭目录会话不会取消历史重播的父请求；父请求取消仍能关闭会话。
- 核心夹具验证指纹偏移、短读取、结果排序、无匹配、大小限制、字幕编码/时间轴和海报歧义。
- Android 夹具验证连续准备两次云盘历史重播、选中态尺寸不变、目录封面缓存以及实际字幕渲染和播放队列保留。
- 公开服务可达性与真实影片命中率是不同证据。合成视频的射手查询返回无匹配；公开历史指纹命中三份候选，实际适配器成功解码两份中文字幕并拒绝一份无法可靠识别编码的结果。Wikipedia 影片海报和 TVmaze 剧集海报均完成查询与下载。没有使用私人云盘凭据或用户影片库验证字幕覆盖率，也没有进行一加真机验收。

协议与资料来源：[TVmaze API](https://www.tvmaze.com/api)、[MediaWiki PageImages](https://www.mediawiki.org/wiki/API:Pageimages)、[SPlayer 开源项目](https://github.com/tomasen/splayer)。字幕协议由映汐独立实现，没有复制 SPlayer 源码。

## 匹配与缓存更新

片名匹配保留续集编号、年份和季集。Wikipedia 查询接受本次精确片名产生的规范化、简繁转换和重定向，例如“小丑2”可以解析到《小丑：雙重瘋狂》。请求允许页面的非自由海报图片，避免默认仅自由图片时挑到其他插图。只有影片页面且年份证据相符时才采用；消歧义、多候选或年份不明时保留视频帧回退。剧集在 TVmaze 未找到唯一匹配时不回退到同名电影。

带有片名的目录封面始终优先。通用 `poster.jpg`、`folder.jpg`、`cover.jpg` 及对应 PNG 仅用于目录内的视频均属于同一片名和年份的情况，避免混合电影目录串图。

海报记录匹配规则、目录身份、匹配置信度、图片来源和核对时间。已保存的图片优先显示，超过 7 天或规则升级时，在后台核对；只接纳置信度不低于 0.96 且不降级的结果，目录海报仍优先。联网失败或结果不确定时保留原图，6 小时内避免重复失败查询。本地读取独立于联网任务槽，不会被慢请求阻塞。旧版规则 2 的明确片名海报会迁入持久目录；目录身份改变的结果不会沿用。设置仍可清理海报，删除记录会阻止旧请求写回。

“小丑2”的回归夹具来自 [Wikipedia 官方 API](https://zh.wikipedia.org/w/api.php?action=query&format=json&redirects=1&converttitles=1&titles=%E5%B0%8F%E4%B8%912&prop=pageimages%7Cpageprops%7Ccategories&pilicense=any&pithumbsize=640&cllimit=50)，采集于 2026-10-20；它验证该时点的公开资料响应，不表示已读取用户媒体目录或核对用户此前的错误图片。

返回首页或将应用切回前台时，会重试缺失的海报，已有且有效的海报继续使用缓存。旧请求在取消或刷新后不能重新写入失败结果；暂时不可读的来源可在恢复连接后再次尝试，标题与同目录海报的匹配规则仍保持一致。

## 数字剧集目录（alpha.21）

`剧名/1.mkv`、`剧名/第2集.mp4`、`综艺名/第3期.mp4` 从父目录取得节目名；`剧名/Season 2/01.mkv` 保留季数并向上一层取名。远程来源选定根目录就是剧名时也可使用，Android 文档 URI 会读取文件目录标识。有明确片名的电影继续按文件名匹配，`电视剧/1.mkv` 等只有泛目录的输入不会猜测。节目先查询 TVmaze 唯一名称结果，再查询有明确电视剧或综艺分类的 Wikipedia 页面；不把普通电影页作为节目结果。

## 同目录外挂字幕（alpha.24）

没有内嵌字幕且用户允许自动匹配时，先在当前影片同目录寻找完整同名的 SRT、ASS、SSA、VTT；允许明确的语言后缀，例如 `Film.chs.srt`、`Film.zh-cn.ass`、`Film.bilingual.srt`。不同集数、清晰度或剪辑版本不会模糊混配。

同目录查找使用独立的读取上下文，不移动正在播放的读取位置。文件限制为 4 MiB，字符编码会转换为 UTF-8；没有可用的同目录字幕时才使用现有在线匹配。手动修改音字幕后，过期的自动查询结果不会覆盖当前选择。

同目录字幕的本机查找使用浏览时记录的 SAF 父目录身份，不从文档 ID 猜测路径。旧历史缺少父目录信息时，重新浏览并播放可补齐；仅授权单个文件时不枚举相邻文件。音轨的全局偏好与手动语言记忆分别保存，关闭记忆后恢复全局偏好。

## 封存项（alpha.33）

封存目录或剧集不会自动向在线海报、字幕服务发送名称或影片指纹；登记封存时取消正在进行的相关查询。字幕保留内嵌轨道与手动导入，不自动查询旁挂或在线匹配。封存是本应用的显示与访问规则，不加密原文件，也不清理第三方此前已收到的信息或已有缓存。


## 同目录轨道与互联网搜寻（alpha.55）

播放前后会在媒体所在目录中查找完整同名的 SRT、VTT、ASS/SSA 和 MKA、M4A、AAC、AC3、EAC3、MP3、FLAC、Ogg、Opus、WAV 音轨。例如 `Film.2024.mkv` 对应 `Film.2024.zh-Hans.srt` 和 `Film.2024.en.mka`；不同剪辑、季集或文件主名不会合并。本机目录使用原有目录授权，SMB/SFTP/WebDAV/云盘沿用已经认证的目录；不会要求重新公开信源。外挂音频按需读取，不预先下载整条音轨。

字幕自动载入；音轨列在播放选项中，有内嵌音轨时可手动选择，无内嵌音轨时由播放器自动选择。二者与主片共用 seek、倍速和暂停时钟。文件本身需匹配同一剪辑和起点；应用没有根据对白自动校准不同版本的音轨。损坏外挂会退出外挂并恢复主片，可重新导入。

alpha.58 起，旧的必应搜音轨和搜字幕入口已移除，字幕使用上方的可配置自动匹配流程。音轨、字幕各有独立播放器按钮；配音仍从影片内部、同目录文件或手动导入获得。外部配音自动下载没有可用服务契约，不把网站说明或网盘链接直接当作已取得音轨。

封存内容允许在解锁状态下加载同目录和本机轨道，互联网字幕/配音搜寻继续关闭。可随时在播放顶部的「播放检修」（竖屏位于「更多播放操作」）复制诊断信息，无须等待播放报错。格式、设备条件及后续方案见[格式清单](playback-format-support.md)。


## 自定义字幕驿站

在**站务 → 字幕驿站 → 自定义**输入搜寻地址，例如 `https://example.org/search/{query}`，然后选择**保存搜寻地址**。地址必须包含一个 `{query}`，只接受不带账号密码的 HTTP 或 HTTPS 地址；片名会单独编码，年份与季集信息可用时一并带入。

播放器的字幕面板会提供**前往字幕驿站**。只有点按后，浏览器才打开该站的片名搜寻页；应用不会自动访问这个自定义网站，也不会假定网站支持直接下载。下载到本机后，用**载入字幕文件**选择字幕。封存档案沿用原有边界，不生成互联网匹配入口。
