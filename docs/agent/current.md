## Beta 阶段已经进入源码的内容

Beta.1 引入跨来源片匣总录、放映单、行囊备份、检修台、影片札记与片刻标记，保留旧片架与历史数据。Beta.2 补齐旧版资料和设置承接，统一 `0.25–4×` 速度保存范围，完善起播中的操作、方向与兼容画面接管，并隔离已确认封存文件的本机别名。

逐项行为见[能力总表](capabilities.md)。面向用户的实际改动只保存在 [Beta.1 信笺](../../releases/v0.2.0-beta.1.md)和 [Beta.2 信笺](../../releases/v0.2.0-beta.2.md)，不改写已发布信笺。

## 验证分别记账

Beta.2 的本地交付记录保存过模拟器功能回归、旧版升级、偏好与授权保留、正式签名 APK 及源码附件核对。那是对应提交与环境的既有证据，本轮文档整理不等于重跑这些验收。公开复现入口见[验证与交付](validation.md)。

参考目标仍是 Android 15/16 手机及 OnePlus Turbo 6V；实际 SDK 与固件必须现场核验。真实 NAS、云盘提供方、参考真机的 4K/HDR 与长期播放表现，不能由模拟器、静态代码或发布成功推导。

本轮对随包世界数据的日常补充属于源码改动；未递增版本或重新构建时，不计入已经安装的 Beta.2 APK。

## 工作树与分支的判定

旧功能工作树可能处在整理历史前的提交。判断承接需要直接祖先，或已核验的等价映射及移除路径说明；不能只凭提交主题判定。清理前保存恢复资料，核对未提交与忽略内容。Dependabot 是独立依赖升级范围，本轮按用户选择保留。
