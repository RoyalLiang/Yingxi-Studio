# 片架、信源与札记界面验证

本轮对应五项界面反馈，基线为 `5091ecab4cdd02e31bc6f87a75d87c4f660d280e`（alpha.58）；候选版本为 alpha.59 / 61。共享工作区的并行改动保留，在隔离副本实现。

## 实现范围

- 今日拾获长按或更多按钮打开播放、封存菜单；选中和键盘焦点只在圆角封面描边。封存沿用已有验证入口，不移动原文件。
- 信源移除登记计数、只读授权复述；实际授权权限及异常处理保留。
- 接入方式下拉统一列出阿里云盘、百度网盘、WebDAV。只渲染所选提供方按钮；阿里授权与百度官方应用跳转沿用现有能力，不增加百度网盘原生浏览能力。WebDAV 在同一窗口切换表单。
- 废墟档案库撤下说明卡、小字，本机文件夹与子目录显示为片架；Android 文件夹授权、实际目录名与数据保留。
- 札记片孔扫光为 5.2 秒行进、1.6 秒停顿的循环；页面暂停时停止，系统关闭动画时静止。动画值仅影响 Canvas 绘制。

## 验证证据

修复前四项 Android 回归均失败，分别准确复现长按无操作、下拉缺少网盘、档案说明文字仍在、首轮后动效静止；修复后共 44 项相关 Android 检查通过：正常动画主批次 40 项、修正旧信笺固定词语断言后的信笺回归 1 项、关闭动画独立进程 1 项、授权目录/剧集入口与大字号历史空页入口 2 项。系统开关在进程启动前设置并在结束后恢复，避免平台动画缩放缓存污染其他用例。正常动效与关闭动画用例分别声明环境前提。新增测试同时覆盖大字号封存入口、信源精简、键盘焦点与 Enter 播放、关闭系统动画。

原生 Android Compose 使用模拟器语义操作、实际像素和屏幕截图检查；网页 DOM 检查器不适用于此界面，未用网页预览代替原生结果。独立 Standards 审查提出一项可见键盘焦点缺口，已修复并经独立静态复核关闭；Spec 审查未发现五项需求遗漏。核心测试 132 项通过、5 项环境跳过；Python 脚本 72 项通过；四 ABI Debug/Release 构建及 lint 通过。原生导航和最终签名产物的核对结果在本轮本地交付记录留证。

## 证据边界

不把源码、模拟器或签名包校验写成真机通过。本轮不重做一加原始 4K P5 持续播放验收，不声称外部字幕网站的匿名下载限制或外部配音接口缺口已消失。百度入口仍为已有官方应用跳转。

`diary_034` 为阿汐、迟灯和放映站既有日常细节，世界书、随包图谱及生成词典同步；没有新增章节、制度、能力或路线。macOS 受保护 provenance 属性不强制清理；源码与分发附件单独检查元数据文件及打包内容。
