# 连接网盘挂载服务与使用设置

## 保存 OpenList 或 WebDAV 为来源

1. 在**来源**页点击添加，选择 **WebDAV**。
2. 填写完整的服务地址，以及该挂载服务的账号和密码。OpenList 通常使用 `https://cloud.example/dav/`，也可填写其中一个子目录。
3. 点击**连接并浏览**。认证和目录读取成功后才会保存来源；服务在线不代表网盘文件一定可读。
4. 点击视频即可播放。同目录队列、上一集／下一集、选集、断点续播沿用现有行为。

映汐连接的是挂载服务。阿里云盘、百度网盘等账号的登录和挂载由服务端完成，不在手机里收集这些网盘的 Cookie 或刷新令牌，也不解析公有分享链接。

优先使用有可信证书的 HTTPS。局域网只有 HTTP 时，需在连接表单中明确勾选**允许明文 HTTP**；此时服务账号和视频在传输中没有加密。密码仍由 Android Keystore 在本机加密保存。自签名证书不会自动信任，也不提供跳过证书验证的开关。

## 保留拖动能力并减少中转

播放器使用 HTTP Range 随机读取。顺序读取复用打开的响应流，每个读取上下文只保留一个内存窗口：首次与跳转读取 64 KiB，连续顺序读取最多 1 MiB，以减少小读取请求；拖动时重新向挂载服务请求相应偏移，服务端返回的偏移和文件总长度都需匹配。忽略 Range 的服务会被明确拒绝，不通过下载整个前缀来伪装可拖动。

读取时可以跟随服务端的 HTTPS 重定向到网盘数据地址，映汐不会把挂载账号的 Basic Authorization 转发给其他 origin。HTTPS 不允许降级到 HTTP。目录请求只能在原 origin 内重定向。每次重新定位都从已保存的挂载地址解析，临时数据地址不写入播放历史。

需要特定请求头时，可在表单中填写 **User-Agent** 和 **Referer**。只在服务要求时设置。例如，OpenList 对百度网盘的文档说明某些下载需要 `pan.baidu.com` User-Agent，速度仍取决于账号权限；启用服务端代理则还受中转带宽影响。[OpenList 百度网盘说明](https://doc.oplist.org/guide/drivers/baidu)

当前为标准 WebDAV 目录浏览，不包含 Emby 影视刮削、海报墙或 Emby 协议客户端。目录响应上限为 4 MiB；需要认证代理、Digest／NTLM 或特殊双重登录的服务尚未验证。真实网盘、无线网络和高码率吞吐需单独验收。

## 从独立设置页检查版本

首页右上角齿轮进入**设置**；底部导航和首页横幅不增加设置按钮。目前只显示 **App 版本**，点击后查看本版说明及**检查更新**。

更新来自当前项目的 GitHub Releases，使用发布资产 `yingxi-release.json`。验证版本允许发现预发布更新，正式版本只接受正式更新；以 Android 安装序号判断是否更新。没有发布资产时显示没有可用更新，网络或校验失败时显示失败，不冒充检查成功。

发现更新后点击**下载并安装**。下载按声明大小限流并计算 SHA256，然后核验包名、版本及证书与当前安装的一致性。校验通过后自动打开系统安装流程；首次需允许映汐安装应用，最终安装仍由 Android 系统确认。取消授权后可再次点击安装。 若离开版本页或系统阻止打开安装器，可返回此页点击**安装更新**。

调试签名包不能通过更新覆盖成另一个签名的正式包。切换发布签名需要另行处理数据迁移，应用不会自动卸载旧版。[Android 安装确认机制](https://developer.android.com/reference/android/content/pm/PackageInstaller.SessionParams#setRequireUserAction(int))

## 开屏和系统栏的行为

开屏由 Android 系统 SplashScreen 承载，使用映汐图标与主界面一致的背景，以 220 ms 淡出衔接首页，不增加第二张开屏、不等待网络发现。系统关闭动画时直接结束过渡。主界面固定浅色，因此状态栏和导航栏固定使用深色图标，并保留系统安全区；播放页继续使用沉浸显示。

本地构建、合成协议和模拟器验证只说明对应实现可运行，不等同于一加 Turbo 6V 或真实 OpenList／网盘环境的性能证明。

## 网盘入口与开发者配置

WebDAV 添加页默认提供阿里云盘、百度网盘的官方 App 入口与未安装提示。开放平台的应用注册、AppID、签名和回调由开发者准备，不交给普通用户填写。当前官方 OAuth 尚未启用，打开 App 不会创建网盘播放来源。已有地址点 **使用 WebDAV 地址** 继续连接。开发者后续步骤见 [网盘官方接入](cloud-integrations.md)。

WebDAV 读取收到可用数据后立即交给播放器，无须等待 64 KiB 或 1 MiB 预读窗口填满。封面提取安排在首帧显示后，避免在起播阶段争抢网络。慢链路测试使用本机合成媒体及限速服务器，结果不能替代实际网盘或 NAS 的吞吐验证。
