使用支持

先找到自己的片库，再安心看完一部片子。

获取 Android 版

映汐主打纯免费、无广告的个人本地播放器。前往 GitHub Releases，阅读对应版本信笺并选择适合设备的安装包。当前主要面向 Android 15 / 16。

查看 Beta.1 安装包 ↗

连接自己的来源

  • 本机文件：通过系统文件与文件夹入口，选择希望播放的内容。
  • 局域网或服务器：选择 SMB、SFTP 或 WebDAV，并填写你有权使用的连接资料。
  • 阿里云盘：从应用的官方授权入口完成接入，具体行为以对应版本说明为准。
