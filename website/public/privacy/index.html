隐私说明

官网隐私说明 · 更新于 2026 年 10 月 28 日

本页说明浏览映汐官网时的信息处理。它不替代 Android 或 iOS 应用的完整隐私政策；应用中的系统权限、媒体来源及网盘授权，需要按平台与对应版本另行说明。

浏览官网

此版网站没有注册、登录或支付功能，没有加入广告与行为分析脚本。只有你主动选择问题上报并同意公开时，才会发送下述检修信息。浏览住民短笺仅在当前页面进行，不向服务器提交你的选择。

页面图片与字体随网站文件提供。媒体文件和网盘密码不会通过这个官网上传。

托管与必要请求信息

当你访问通过 Cloudflare Pages 发布的官网时，Cloudflare 会提供网页与安全防护，并可能处理 IP 地址、请求时间、浏览器及必要请求信息，实际处理以 Cloudflare 隐私政策为准。本地预览不经过 Cloudflare。

自愿提交播放问题

应用内与官网的播放问题上报，会在你同意后将应用版本、设备与系统型号、编码及播放性能字段发布到公开的 GitHub Issues。上报字段经过白名单筛选，不包含影片标题、媒体地址、路径、账号或授权信息；不上传媒体文件。公开内容适用 GitHub 的隐私规则。

上报通道使用 Cloudflare Turnstile 进行后台安全校验。Cloudflare 会处理 IP 地址、浏览器与连接特征等必要信号，具体见 Turnstile Privacy Addendum。这些连接信息不会写入公开问题正文。

应用只在本机保存尚未确认上报的随机请求标识，供你检查上一次回执，不保存诊断正文。结果未明时不会自动重发。

下载与问题反馈

下载、源代码和问题反馈入口会带你前往 GitHub，适用对应服务的隐私规则。请勿在公开反馈中附上密码、访问令牌、私有服务器地址或个人影片文件。

应用中的媒体与来源

映汐播放你选择的文件或授权访问的媒体来源。系统文件权限、局域网访问和网盘授权，需要根据安装平台与具体版本分别说明。正式应用上架前，将补齐与该版本一致的应用隐私政策及商店隐私声明。

联系项目维护者

你可以通过 GitHub Issues提出官网相关问题。涉及隐私时，请先说明问题类型，不要直接公开个人资料。
