# 映汐官网设计与验证记录

## 已采用的方向

用户指定 taste 与 finesse-ui；在首版审阅后，改为 Apple 产品官网的版式与动效。参考 Apple 中国 iPhone 产品页的视觉节奏，自行实现页面，没有复制其图片、品牌或网页代码。

主标题「你的片库，自在放映」，紧邻产品身份「映汐 · 个人本地播放器」。免费使用、无广告作为正文事实说明，避免作为标题或价格大数字展示。

浅灰与白色产品篇幅、大字与居中界面舞台、圆角横向亮点图库、粘性滚动聚焦；深色世界篇幅呈现纪元、灾变、聚居地、地图、共生生态与住民关系。版面使用映汐红与现有原创角色肖像。世界事实依照世界书，路线待核、角色身世和觉醒状态不作新确认。

## 交互

- 产品舞台随滚动轻移，桌面播放篇幅粘性聚焦；窄屏改为正常文档流。
- 亮点图库可拖动或使用前后按钮。
- 最新实际播放器录屏仅在可见、页面活跃且未选择减少动态效果时播放；提供暂停按钮。
- 世界档案与住民短笺使用原生 dialog，支持 Escape、关闭按钮与焦点归还。
- 故事、常见问题和住民短笺都有不依赖动画的文字呈现。

## 审美规则的取舍

用户明确要求 Apple 样式，因此保留圆角图库、轻阴影、局部半透明导航、分隔线与产品名称行，优先于 taste 的默认禁用项。字体改为覆盖中文的 Noto Sans SC，本地保留变量字重；原抽签的西文字体不再适用。

图库的横向裁切为可操作布局，提供箭头与滑动；原生 Android 截图中的米色属于真实应用界面。正文灰度满足普通文字对比要求，世界段使用更亮的灰与低饱和暖色。桌面与手机分别调整字号和密度。

## 当前边界

素材固定绑定 alpha.52 / code54，包括新版竖屏播放页；七张截图与八秒录屏均来自正式签名 APK 的实际运行，素材清单记录摘要。官网为静态页面，下载指向对应公开 Release。Cloudflare 项目为 `yingxi-station`，正式地址为 `https://yingxi-station.pages.dev`。官网隐私说明不替代完整应用上架隐私政策，iOS 仍为开发预览。

## 已执行的检查

- taste 真实浏览器检查：1440×900、768×1024、390×844、320×760，横向页面溢出均为0，未留下 FAIL。320宽使用正常手机高度，避免工具默认的320×200短视口影响判断。
- 正常模式记录19至23个元素的实际入场动画；检查器还执行减少动态效果分支。
- IAB 实际操作：图库下一项、世界档案、Escape关闭、阿汐短笺、支持页均可用；播放器录屏已观察到时间推进，暂停与恢复按钮正常。
- 本地静态检查核对链接、锚点、字体、媒体校验和、三位住民的随包原文与Cloudflare单文件大小限制。
- 世界书检查、17项世界数据测试与3项源码准入测试通过；保留并行 alpha.52 的正式设定。没有发布新应用版本。

检查器仍提示圆角卡片行、字号数量、灰色正文与横向图库，这些是本次用户指定的产品官网方向；字体差异来自中文覆盖需求。首屏已明确写出个人本地播放器，中文标题被规则误判为只有名称。上述提醒已人工核对。

## 2026-10-24 落地复核

- alpha.52 更新后，1440、768、390 宽度真实浏览器复核无横向溢出、无损坏图片；滚动入场与减少动态效果分支已检查。原 320 宽度设计检查仍作为前版布局证据。
- 更新了真实竖屏播放截图、下载版本、媒体摘要、当前住民短笺与中文字体子集。
- 部署脚本拒绝预览使用 main、未提交的跟踪改动和 public 中未跟踪文件。正式发布还要求设置真实站点元数据。
- GitHub 工作流执行静态校验并归档页面；手动部署需要另行配置 website environment 的 Cloudflare 秘密。本地 OAuth 登录不自动建立 CI 凭据。

## 世界档案扩充

首页保留产品主线与世界入口，独立 world/ 页面展开完整阅读。采用既有深色世界篇幅、暖灰字色与大标题，以实际六处节点的可点击联系图串起地点；住民沿用三幅原创肖像。图谱、人物描述与28个词条节录来自当前随包数据，完整页由脚本生成并在 CI 核对，避免把站内传闻当成路线实测。
