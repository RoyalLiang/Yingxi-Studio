# 映汐播放器 iOS 0.1.0-alpha.1 / Yingxi Player iOS 0.1.0-alpha.1

## 中文

### 更新内容

- 首个面向 iOS 27 的 SwiftUI / AVFoundation 原生 alpha，支持本机视频导入、HTTPS WebDAV 目录浏览、有认证的 Range 视频读取与播放记录续播。
- 使用系统播放控件；密码存入本机钥匙串，不进入视频 URL；限制目录访问范围，跨站媒体重定向移除来源认证信息。
- 提供未签名设备 IPA 与模拟器 App 压缩包。设备 IPA 必须自行签名后安装；模拟器包的 CPU 架构见附带元数据。

### 验证与限制

- 发布流程要求使用 iOS 27 或更新 SDK 构建，运行 WebDAV 核心测试，并在 iOS 27 模拟器启动和解码受控本地视频；结果以附带的 ios-validation.json 为准。
- 没有 Apple 开发者签名、描述文件或 TestFlight 分发；未进行真实 iPhone、真实 NAS / WebDAV 吞吐和长时间稳定性验证。
- 此版使用 iOS 原生解码能力，不等同 Android 功能集；SMB、SFTP、网盘官方 OAuth、Android 自定义手势和非原生容器解码尚未接入。远程播放需要 HTTPS、有效证书及可用的 HTTP Range。

## English

### Changes

- Initial native SwiftUI / AVFoundation alpha targeting iOS 27, with local video import, HTTPS WebDAV browsing, authenticated byte-range playback and resume history.
- Uses system playback controls, device-only Keychain credentials, source path boundaries and credential stripping on cross-origin media redirects.
- Ships an unsigned device IPA and a simulator app archive. The IPA requires your own signing before device installation; the simulator architecture is recorded in metadata.

### Validation and limitations

- Publication requires an iOS 27-or-newer SDK build, WebDAV core tests and confirmed local-video decoding on an iOS 27 simulator. The attached ios-validation.json records actual results.
- No Apple developer signature, provisioning profile or TestFlight upload. Physical iPhone, real NAS / WebDAV throughput and long-running stability remain unverified.
- Uses native iOS codec support and is not at Android feature parity. SMB, SFTP, official cloud-drive OAuth, Android custom gestures and additional container decoding are not implemented. Remote playback requires HTTPS, trusted certificates and byte-range support.
