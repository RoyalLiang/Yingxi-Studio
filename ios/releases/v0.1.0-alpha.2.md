# 映汐播放器 iOS 0.1.0-alpha.2 / Yingxi Player iOS 0.1.0-alpha.2

## 中文

### 更新内容

- 接入阿里云盘公开客户端 PKCE、官方 Universal Link 与原生授权回跳；账户令牌保存在仅本机 Keychain。
- 支持默认盘分页目录、文件夹优先与名称自然排序、云盘视频分段播放和稳定文件标识续播；过期下载链接可重新获取一次。
- 移除账户使迟到授权/刷新失效，播放解析按最新意图提交；沿用本机导入、HTTPS WebDAV 与系统全屏播放。

### 验证与限制

- 使用 Xcode / iOS 27 SDK 构建；Swift 核心测试、模拟器启动与受控本地视频解码结果见附带报告。
- 官方 AppLink 授权入口已核对；真实 iPhone 的网盘授权、回跳和云端视频仍待联调。没有 Apple 签名或 TestFlight 分发，设备 IPA 必须自行签名；保持已登记 Bundle ID 或同步开放平台。
- 需要阿里云盘官方 App。平台配额、公开客户端刷新和原生解码能力仍受实际环境约束；百度、SMB、SFTP 尚未接入。移除本地账户不等同平台撤销授权。

## English

### Changes

Adds Aliyunpan public-client PKCE, official Universal Links/native callbacks, device-only Keychain credentials, paginated browsing, natural ordering, ranged cloud playback and stable file-ID history. Late authorization/refresh results cannot restore removed accounts; newer playback requests take precedence.

### Validation and limitations

Built with Xcode/iOS 27 SDK. Core tests, simulator launch and controlled local-video decode evidence are attached. The official public AppLink endpoint is verified; real iPhone consent, callbacks and cloud playback require integration testing. The IPA is unsigned and must be signed by the user; keep the registered Bundle ID or update provider configuration. The official Aliyunpan app is required. Provider quotas, refresh support and native codecs apply. Baidu, SMB and SFTP remain unsupported. Local removal does not revoke the provider grant.
