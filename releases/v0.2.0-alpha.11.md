# 映汐播放器 0.2.0-alpha.11 / Yingxi 0.2.0-alpha.11

## 中文

### 更新内容
- 来源行移除左侧图标和分散操作，长名称完整换行；通过“…”菜单管理设置、收藏、分组、置顶、私密访问和删除。
- 来源设置支持重命名及浏览选择默认进入目录，也可恢复来源根目录；保留账户凭据、来源身份、收藏和分组，云盘重新授权与令牌续期保留这些显示设置。
- 收藏与取消收藏显示对应提示，连续点击读取最新状态；首页完全移除网络来源入口和来源列表。
- 左右滑动使用独立圆角操作按钮、阻尼与回弹；设置面板和菜单沿用统一样式；Toast 移至顶部安全区，成功提示为紧凑胶囊，错误可展开详情。

### 验证与限制
- 独立 SDK35、SDK36 模拟器各 33 项相关回归通过，覆盖长名称与大字体、菜单、默认目录持久化与取消、凭据和来源身份保留、云盘凭据更新、收藏连续切换、首页、滑动、协议转场及 Toast 生命周期。
- 核心 JVM 37 项中 34 项通过、3 项外部依赖测试跳过；Python 35 项通过。Android Lint 无错误；依赖更新、平台配置和既有代码建议仍有警告。
- 默认进入目录是浏览起点，可继续访问其上级目录。实际 NAS、云盘账户全流程和一加真机的滑动帧率、玻璃效果功耗尚未重新验证；模拟器与合成连接器证据不等同现场能力。
- 延续正式签名和仅安装包与源码的 Release 策略；iOS 继续暂停发布。

## English

### Changes
- Gives source names the full row width with wrapping text and one ellipsis menu for settings, favorites, groups, pinning, private access and removal.
- Adds renaming and a folder browser for the default entry directory, including reset to the source root. Preserves credentials, source identity, favorites and groups; cloud reauthorization and token renewal retain presentation settings.
- Distinguishes favorite and unfavorite feedback and reads the latest state on every toggle. Removes all network-source entries and source lists from Home.
- Refines swipe actions with separate rounded buttons, resistance and spring settling, aligns menus and settings, and moves compact glass feedback to the top safe area with expandable error details.

### Validation and limitations
- All 33 related regressions passed on each independently owned SDK35 and SDK36 emulator, covering long names, larger text, menus, default-directory persistence and cancellation, credential and source-identity retention, cloud credential renewal, repeated favorite toggles, Home, swipes, protocol transitions and feedback lifetime.
- Core JVM: 34 passed and 3 external-fixture tests skipped out of 37. Python: 35 passed. Android Lint has no errors; dependency updates, platform configuration and existing code suggestions still produce warnings.
- The default directory is an entry point and does not restrict parent navigation. Real NAS and cloud-account flows, OnePlus swipe frame rate and glass-effect power use have not been revalidated. Emulator and synthetic-connector evidence does not establish field behavior.
- Retains production signing and installer/source-only releases. iOS publishing remains paused.
