# 映汐放映站 0.2.0-alpha.59 / Yingxi 0.2.0-alpha.59

## 中文

- 放映站里今日拾获的片匣留出一枚操作钮，长按也能打开播放与封存；选中时只沿圆角封面描边。
- 信源收起登记数量与权限复述，接入方式在同一处挑选；选中网盘后，只留下它自己的接入按钮。
- 废墟档案库撤下说明小字，文件夹归回本机片架，片名与原目录仍留在原处。
- 札记底部的灯沿着片孔缓缓走过，歇一会儿再来；离开页面或关闭系统动画时收住光。

找一部旧片，先从眼前认得出的字开始。——阿汐
