# 映汐播放器 0.2.0-alpha.13 / Yingxi 0.2.0-alpha.13

## 中文

### 更新内容

- WebDAV 收到数据即交给播放器，避免为填满预读窗口而延迟起播；封面提取延后到首帧之后。
- 进度圆点与轨道居中对齐，收紧全屏按钮间距；目录收藏和分组按钮保持单行，移除来源目录的“文件浏览”副标题。
- 音轨与字幕使用局部可滚动面板，倍速保留独立入口；预览提取允许慢链路等待，并复用 alpha.12 的独立解码会话。
- 基于 alpha.12 增量发布，安装序号为 15。来源探测时长按用户要求暂不调整。

### 验证与限制

- 慢速 WebDAV JVM 回归验证首批数据不再等待预读填满；核心测试 35 项通过（另 3 项需 SMB 集成环境），发布脚本 40 项通过，Lint 无错误；SDK 35/36 各 12 项专项回归通过。
- 专项覆盖进度条像素对齐、大字体目录按钮、音字幕面板、独立倍速、实际 WebDAV 首帧、拖动预览和封面解码。测试使用合成视频及本机限速服务。
- 真实手机、NAS、OpenList、网盘限速和运营商链路仍需现场验证。安装包源码提交与签名由 Release 的元数据和校验文件绑定。

## English

### Changes

- Return available WebDAV bytes immediately instead of waiting to fill read-ahead windows, and defer optional artwork until after the first video frame.
- Center the timeline thumb on its track, group fullscreen controls more tightly, keep folder favorite/group labels on one line, and remove the redundant browser subtitle.
- Show audio and subtitles in a bounded, scrollable panel with speed controls kept separate. Allow slow-network previews more time while preserving alpha.12 decoder reuse.
- Build incrementally on alpha.12 with version code 15. Discovery duration remains unchanged as requested.

### Validation and limitations

- A throttled WebDAV JVM regression checks that initial bytes are returned without filling read-ahead buffers. 35 core tests passed (3 require an SMB integration fixture), 40 release-script tests passed, Lint reported no errors, and all 12 focused tests passed on each of SDK 35 and 36.
- Focused coverage includes painted timeline alignment, large-text folder controls, track panels, separate speed controls, rendered WebDAV video, seek previews and artwork decoding using synthetic media and a loopback throttled server.
- Physical phones, NAS, OpenList, cloud-provider throttling and real network throughput remain unverified. Release metadata and checksums bind the APK to its actual source commit and signing identity.
