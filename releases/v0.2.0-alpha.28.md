# 映汐放映室 0.2.0-alpha.28 / Yingxi 0.2.0-alpha.28

## 中文

【拾荒者信笺】

放映站给解码器备了一条能接着走的路。

【修缮记录】
1. 增加内置 HEVC 软件解码回退。设备解码器不可用、实际解码失败，或有声音却持续没有首帧时，自动尝试兼容解码。
2. 无法解析的 HEVC 编码标识，改从视频自身的初始化数据读取真实参数，再交给解码器，不凭标识猜测位深或等级。
3. 回退时保留播放队列、当前集、进度和播放／暂停状态；切换到下一集时重新优先使用设备解码。
4. 应用按 GPLv3 开源发布，保留软件解码组件的许可、精确版本和对应源码指引。

> 银幕上的人动起来，我才敢把工具收回箱里。——迟灯

## English

[Scavenger's letter]

The projection station has fitted a spare route through the decoder rack.

[Repairs]
1. Add a bundled HEVC software fallback. Try compatible decoding when the device decoder is unavailable, actually fails, or keeps playing audio without a first video frame.
2. When an advertised HEVC codec string cannot be parsed, read the real parameters from the video's initialization data before configuring the decoder.
3. Preserve the queue, episode, position and play/pause state during recovery. Give the device decoder priority again for the next episode.
4. Publish the application under GPLv3, with decoder licenses, exact dependency versions and corresponding source directions.

> I'll put the tools away when the people on the screen start moving. — Chideng
