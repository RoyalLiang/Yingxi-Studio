# 映汐播放器 0.2.0-alpha.17 / Yingxi 0.2.0-alpha.17

## 中文

【拾荒者信笺 · 映汐放映站 0.2.0-alpha.17】

路标排齐了，点下去的那一格也该留在原处。这封信，记下片架与目录之间的几处修缮。

【修缮记录】
1. 文件夹读取中的提示移回原有工具栏，不再把正在点击的目录行往下挤；选中的行显示读取状态，进入下一级后及时收起旧标记。
2. 收藏与分组收进顶部的更多菜单，不再单独占一行。走进哪个文件夹，操作就记在哪个文件夹名下。
3. 普通浏览的面包屑改为只读层级，从选定的根目录开始显示，不再把更上层的路标摆出来；在这个根目录返回时回到来源列表。重新选择默认目录时仍可浏览上层。
4. 回到首页时重新尝试补齐缺失海报，首次获取失败后不必守着旧结果等待。已有封面继续留在片架上，过期请求不会把旧失败重新写回来。

## English

[Scavenger's letter · Yingxi Projection Station 0.2.0-alpha.17]

Once the signposts are aligned, the folder under your finger should stay in place. This letter records a few repairs between the directory and the film shelf.

[Repairs]
1. Keep folder-loading feedback in the existing toolbar so the pressed row stays in place. Show its pending state, then clear the old selection after entering the next directory.
2. Move favorites and grouping into the top overflow menu. They apply to the folder currently being browsed, without taking a separate row.
3. Make ordinary browsing breadcrumbs read-only and begin at the selected root. Back from that root returns to Sources; choosing a different default folder still allows browsing higher levels.
4. Retry missing posters when returning home. A temporary miss no longer leaves the shelf waiting on an old result; existing artwork stays visible and stale requests cannot restore obsolete failures.

With two signs moved off the counter, the corridor feels wider. The night keeper has wiped the empty frame once more, ready for its next poster.
