# 映汐 0.2.0-alpha.4 / Yingxi 0.2.0-alpha.4

## 中文

### 更新内容

- 新增影院悬浮播放控件，默认横屏沉浸；点击当前倍速可选 0.75、1、1.25、1.5、2、4×，使用细进度条和右侧半透明选集抽屉。
- 新增左侧亮度、右侧音量、横向定位手势，以及目标时间和真实关键帧预览；保留方向锁定、画面比例、音轨和字幕选择。
- 首页前台自动发现局域网服务，SMB 认证后枚举并验证共享；改进 SMB/UNC 地址输入、来源与目录收藏分组、本机加密密码和跨协议路径处理。
- 目录使用名称自然排序，可取得创建时间时用于同名排序；本机、SMB/SFTP 队列支持上下集、选集和连续播放，媒体通知与画中画保留当前队列。
- 远端读取使用 64 KiB 起始窗口、连续读取扩展到最多 1 MiB；有界播放缓冲、预览缓存和控件可见性更新减少读取及渲染开销。
- 改进首页、紧凑续播与历史、滑动来源、最多 3 个置顶、删除确认和一次性系统验证访问。新增独立设置、版本检查与校验下载、系统安装入口、启动过渡、浅色系统栏及标准 WebDAV/OpenList 长期来源。

### 验证与限制

- 发布门禁包括源码与敏感信息检查、Python/JVM 测试、Android 编译、Lint、正式签名和资产校验；发布元数据记录源码 SHA、APK SHA256、版本和签名指纹。
- Android 15/16 模拟器与受控回环协议验证不能代替一加 Turbo 6V、真实 NAS、无线网络或高码率样片验收。当前没有引入 QUIC 传输。
- 队列最多包含点选项附近 200 项，进程结束后需重新打开。预览按约 5 秒采样请求关键帧，编码或文档提供方不支持时显示时间与不可用提示。缺少可靠创建时间的来源不会以修改时间替代。
- 一次性系统验证只保护本次打开，不是永久来源锁，历史记录照常保存。正式签名与旧 debug 签名不同，不能覆盖安装；卸载会清除本地来源、文件授权和历史。

## English

### Changes

- Adds cinema-style floating controls and landscape immersive playback by default. The current speed opens 0.75, 1, 1.25, 1.5, 2 and 4× choices, with a slim timeline and translucent right-side episode drawer.
- Adds brightness, media-volume and horizontal seeking gestures, target timestamps and real keyframe previews, alongside orientation lock, aspect ratio, audio and subtitle controls.
- Adds foreground LAN discovery on Home, authenticated SMB share enumeration and readability checks, improved SMB/UNC entry, source and folder favorites and groups, encrypted local credentials and protocol-specific path resets.
- Uses natural name ordering with available creation times as a secondary key. Local, SMB and SFTP episode queues support previous, next, selection and continuous playback, with queue identity retained through media notifications and picture-in-picture.
- Uses a 64 KiB initial read window that grows to at most 1 MiB for sequential access, bounded playback and preview caches, and visibility-aware control updates.
- Refines Home, compact resume and history rows, swipe actions, three pinned sources, deletion confirmation and one-time system authentication. Adds settings, version checks, verified update downloads, the system installer, launch transitions, light system bars and standard WebDAV/OpenList sources.

### Validation and limitations

- Release gates cover source and secret checks, Python/JVM tests, Android compilation, Lint, signing and asset integrity. Local regression coverage spans 56 cases on each actual SDK 35/36; the final candidate passes nine affected-feature cases per SDK, 22 core tests and 14 Python tests. Release metadata records the source SHA, APK SHA256, version and signing certificate.
- Android 15/16 emulators and controlled loopback protocol validation do not establish OnePlus Turbo 6V, real NAS, wireless or high-bitrate playback acceptance. No QUIC transport is introduced.
- Queues contain at most 200 items around the selected video and must be reopened after process death. Previews request keyframes in roughly five-second buckets; unsupported codecs or document providers retain timestamp feedback. Missing creation times are not replaced with modification times.
- System authentication applies to one open action, not a permanent source lock; history remains enabled. The release certificate differs from earlier debug builds, so an in-place upgrade is unavailable. Uninstalling clears local sources, document grants and history.
