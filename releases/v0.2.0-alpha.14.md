# 映汐播放器 0.2.0-alpha.14 / Yingxi 0.2.0-alpha.14

## 中文

### 更新内容

- 修复阿里云盘官方接入的最近播放重开失败：目录会话关闭不再取消后续重播请求，保留父请求取消能力。
- 最近播放卡片采用淡色底和细描边表示选中状态，提供选中语义，切换状态时保持卡片尺寸。
- 自动海报优先读取目录封面，再按整理后的片名、年份或季集匹配 Wikipedia / TVmaze；保留视频帧回退、来源链接、缓存清理和开关。
- 接入射手字幕公开指纹接口：没有可用内嵌字幕时后台匹配，支持手动重试；简体中文优先、兼容双语，可设置双语优先。支持 SRT、ASS/SSA、WebVTT、UTF-16、GB18030、Big5、gzip 及字幕时间偏移。
- 安装序号递增至 16，基于 alpha.13 增量发布。

### 验证与限制

- 核心测试 51 项通过（另 3 项需 SMB 集成环境），发布脚本 40 项通过；Debug 构建成功，Lint 0 错误、41 项已有提示；SDK 35/36 各 22 项专项回归通过。
- 字幕加载验证保留播放队列和位置并渲染字幕；云盘重播验证准备流程，未使用私人账户进行真实云盘或一加真机验收。
- 在线海报和字幕覆盖率依赖外部资料源。射手公开历史指纹命中三份候选，两份中文字幕经实际适配器解码、一份编码异常被拒绝；Wikipedia / TVmaze 海报完成公开查询与下载。此结果不能代表用户影片库覆盖率，字幕语言描述也可能不完整。自动查找失败可手动加载字幕。
- 海报查询发送整理后的片名和年份；字幕查询发送影片指纹与文件名。不上传完整影片、云盘凭据或服务器地址。图片权利见来源页。

## English

### Changes

- Fix repeated playback from Aliyun Drive history: closing a directory session no longer cancels the parent replay request; parent cancellation still closes the session.
- Add a subtle fill, outline, and selection semantics to recent cards without changing their dimensions.
- Prefer directory posters, then match normalized film titles, years, or episode identities through Wikipedia / TVmaze. Keep frame fallback, source attribution, cache cleanup, and an opt-out.
- Integrate Shooter's public fingerprint subtitle API with automatic lookup when embedded captions are unavailable and a manual retry action. Prefer Simplified Chinese, accept bilingual captions, and offer bilingual priority. Support SRT, ASS/SSA, WebVTT, UTF-16, GB18030, Big5, gzip, and timing offsets.
- Increment Android versionCode to 16 from alpha.13.

### Validation and limitations

- Pass 51 core tests (3 additional SMB fixture tests skipped), 40 release-script tests, Debug builds, and Lint with zero errors and 41 existing warnings. Pass 22 focused tests on each of SDK 35 and 36.
- Check subtitle rendering while preserving the queue and position, plus repeated preparation of cloud history. No private cloud account or physical OnePlus acceptance was performed.
- Public metadata coverage depends on external services. A public historical fingerprint returned three candidates: the actual adapter decoded two Chinese captions and rejected one uncertain encoding. Wikipedia and TVmaze poster queries and downloads succeeded. This does not establish user-library coverage or universal language accuracy. Local subtitle loading remains available.
- Poster requests send normalized titles and years. Subtitle requests send the fingerprint and filename, never the complete video, cloud credentials, or server address. Image rights remain with their source pages.
