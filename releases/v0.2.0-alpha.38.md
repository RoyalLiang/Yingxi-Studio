# 映汐放映站 0.2.0-alpha.38 / Yingxi 0.2.0-alpha.38

## 中文

【拾荒者信笺】

线盘松开了死结。远处送来的影像，不必每取一小段都等回声落定。

【本次修缮】

1. SMB/SFTP 连续读取启用有界请求窗口，先轻取首块，确认连续读取后再展开预读，减轻高延迟连接中的等待。
2. 拖动时丢弃旧位置的预读；取消 SMB 播放时及时切断等待，避免旧请求拖住离开。
3. 本机日志增加文件打开耗时、读取等待与实际解码器记录，这些计数不含文件路径、服务器地址或账号。影片分辨率、码率与色彩处理沿用原配置。

> 线盘别缠死。留一截松线，下次检修才不必把整架拆开。——迟灯

## English

[Scavenger's letter]

The cable reel is untangled. Images from farther away need not wait for an echo after every small piece.

[Repairs this time]

1. SMB and SFTP use bounded read windows. They fetch a small first block, then expand prefetch once reading continues, reducing waits on high-latency links.
2. Seeking discards prefetch for the old position. Cancelling SMB playback promptly interrupts the wait instead of leaving old requests in the way.
3. Local logs record file-open time, read waits and the active decoder. These counters contain no file paths, server addresses or account names. Film resolution, bitrate and color processing keep their existing settings.

> Leave some slack on the cable reel. The next repair should not mean taking the whole rack apart. — Chideng
