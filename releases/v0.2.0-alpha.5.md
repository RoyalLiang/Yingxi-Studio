# 映汐 0.2.0-alpha.5 / Yingxi 0.2.0-alpha.5

## 中文

### 更新内容
- 首页续播独立准备媒体和播放列表，保持正在浏览的目录；卡片原位显示加载状态，避免页面高度跳变与重复点击。播放器采用短淡入过渡。
- 点击底部来源入口、首页网络来源或历史页来源入口时，先显示来源列表；从列表打开来源后继续保留正常目录浏览。
- 播放控件显示根据实际视频尺寸计算的 1080P、2K、4K 等清晰度标识，支持竖屏视频；不提供虚假的清晰度切换。
- 改进液态玻璃的半透明材质、边缘折射和毛玻璃；缓存绘制效果，底栏选中状态使用图层位移。
- 保留已经显示的缩略图，避免其他图片加载通知导致闪烁。连续拖动时合并待处理预览请求、保留上一张有效画面，并显示对应预览时间和更新状态。

### 验证与限制
- 使用 Android 15/16 模拟器与受控环回媒体源验证，不能代替真实 OnePlus、NAS、无线网络或高码率视频验收。
- 清晰度来自实际媒体尺寸，不能保证设备具备对应分辨率的实时解码性能。预览仍使用约五秒关键帧区间，网络超时或不支持的格式保留时间反馈。
- 使用与 alpha.4 相同的正式签名，可按版本正常升级；早期 Debug 签名不同，卸载会清除来源、文件授权和历史。

## English

### Changes
- Prepare resumed media and its queue independently from directory browsing. Keep loading feedback inside the existing continue card, prevent repeated taps and use a short fade into playback.
- Open the saved-source catalog from the bottom source tab, the home network-source entry and the history source entry. Opening a saved source still enables normal folder browsing.
- Show a read-only definition badge such as 1080P, 2K or 4K from the actual video dimensions, including portrait video.
- Refine translucent glass, edge refraction and frosting. Cache drawing effects and move the navigation indicator in a graphics layer.
- Keep valid artwork during cache updates. Coalesce pending seek-preview requests during continuous dragging and retain the previous frame with its preview time and update state.

### Validation and limitations
- Android 15/16 emulators and controlled loopback media do not establish physical OnePlus, NAS, wireless or high-bitrate acceptance.
- The definition badge describes media dimensions rather than decoder performance. Previews still use roughly five-second keyframe intervals; time feedback remains available when previews are unsupported or time out.
- This release uses the same production certificate as alpha.4. Earlier Debug builds use a different certificate; uninstalling clears sources, document permissions and history.
