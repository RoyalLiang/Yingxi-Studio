# 映汐放映站 0.2.0-alpha.39 / Yingxi 0.2.0-alpha.39

## 中文

【拾荒者信笺】

检修纸多留了一栏。哪盏灯没亮，等了多久，先记下来，再伸手去找接头。

【本次修缮】

1. 放映长时间等待时，可查看当前是在连接来源、读取影片，还是已收到数据仍在等待画面，并主动复制一份检修记录。
2. 检修记录包含应用版本、手机型号、系统版本、读取等待、缓冲与解码器状态，不包含影片名称、文件路径、服务器地址、账号或密码，也不会自动上传。
3. 等待界面保留播放与返回操作，检修记录入口适配窄屏、大字号与无障碍读取。

先记哪盏灯先灭，再拿钳子。一次换三根线，谁也说不清是哪根坏了。——迟灯

## English

[Scavenger's letter]

The repair slip has another column. Note which lamp stayed dark and how long it waited before reaching for a connector.

[Repairs this time]

1. During a long playback wait, see whether the player is connecting, reading, or waiting for a picture after receiving data, and choose to copy a repair record.
2. The record includes the app version, phone model, Android version, read waits, buffering and decoder state. It excludes film names, file paths, server addresses, accounts and passwords, and is never uploaded automatically.
3. Playback and back controls remain available while waiting. The repair-record action supports narrow screens, large text and accessibility navigation.

> Note which lamp went dark first, then reach for the pliers. Change three wires at once and nobody knows which one was faulty. — Chideng
