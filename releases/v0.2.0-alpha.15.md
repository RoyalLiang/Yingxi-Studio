# 映汐播放器 0.2.0-alpha.15 / Yingxi 0.2.0-alpha.15

## 中文

【拾荒者信笺 · 映汐放映站 0.2.0-alpha.15】

长潮退去，柜台又收到几封问路的信。这一回，我们先把入口摆正，再把该递到手边的东西递到手边。

【本次实装】
1. 自动扫描有了独立一列。SMB、SFTP / SSH 和 WebDAV 的服务广播归到同一个入口；发现的仍是候选，连上之后才知道里面装着什么影片。
2. “版本与更新”重新整理了柜台。检查、下载和安装留在手边，新信笺用弹窗展开，不必翻完整页再寻找按钮。
3. 映汐放映站开始留下自己的记录。README 换上实用入口、界面实拍、功能支持矩阵和源码活跃度图，想读故事或直接看片，都能找到路。

【修缮记录】
1. 更新请求不再反复敲同一扇旧缓存的门；版本号与对应信笺一同出现，取消旧请求后也不会盖掉新消息。
2. 修正深色系统中新建来源时的状态栏文字。白纸铺开的时候，字也该看得清。
3. 发版规则补上短笺语气的约束，保留段落和编号清单。技术记录留在工作簿里，递到手里的信只写这一回搬来了什么、修好了哪里。

【放映站手记】
值夜人把下载按钮搬近以后，终于不必一手举灯，一手把信翻到最末页了。

## English

[Scavenger's letter · Yingxi Projection Station 0.2.0-alpha.15]

The long tide has receded, and a few more letters asking for directions have reached the counter. This time, the entrances are clearer and the things you need are closer to hand.

[New arrivals]
1. Automatic discovery has its own row. SMB, SFTP / SSH, and WebDAV service announcements share one entrance. A discovery is still a candidate; connect before browsing its films.
2. The version and update counter has been rearranged. Check, download, and install actions stay within reach, while each new field letter opens in a scrollable dialog.
3. The projection station now keeps a continuous record. The README brings together practical entry points, real screenshots, a capability matrix, and a source-activity chart.

[Repairs]
1. Update checks no longer keep knocking on the same stale cache entry. Version identity travels with its letter, and an old cancelled request cannot overwrite a new message.
2. Restore readable status-bar text when a light source sheet opens over a dark system theme.
3. Give the field-letter voice a place in the release rules. Preserve paragraphs and numbered lists. Technical evidence stays in the work log; the letter tells you what arrived and what was repaired.

[Station journal]
With the download button closer to the counter, the night keeper can finally stop holding a lamp in one hand and searching the last page with the other.
