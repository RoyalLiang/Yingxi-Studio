# 映汐放映站 0.2.0-alpha.64 / Yingxi 0.2.0-alpha.64

## 中文

【拾荒者信笺】
柜台把多余的路牌收了起来，留下眼下要做的一步。

【本次实装】
1. 字幕来源改称「字幕驿站」，添上自定义搜寻地址；写入含 {query} 的网址，就能从播放器按片名去找字幕。
2. 站务中的读取设置改称「信号采集频段」，字幕来源下方的说明收起。

【修缮记录】
1. 检查更新失败时，原因直接在顶部居中短暂提示；更新柜台只保留一个当前操作，下载、暂停与安装各归其位。
2. 更新安装直接接往系统确认，撤去中间准备页，并拦住重复发起。
3. 打开影片时优先沿用已知画面方向，不再为网络影片额外等待方向探测；方向尚未知时先以横屏入场，读到真实画面属性后自动校准。

「来处记在纸头，认不清的字先空着。明早找原文，纸堆也不用翻乱。」——阿汐

## English

[Scavenger letter]
The counter has put away its extra signposts, leaving the next useful step in view.

[New arrivals]
1. Subtitle sources now live at the Subtitle station, with a custom search address. Save a URL containing {query} to look up the film from the player.
2. The remote-read setting is now named Signal collection bands. The explanation beneath subtitle sources has been cleared away.

[Repairs]
1. A failed update check explains itself in a brief message at the top center. One current action handles downloading, pausing, or installing.
2. Updates lead straight to Android’s confirmation without an intermediate preparation page, and repeated installation requests are held back.
3. Films reuse their known display direction without an extra network metadata wait. Unknown footage opens in landscape and adjusts when its actual dimensions arrive.

“Sources go on the tabs; unclear words stay blank. Tomorrow we can find the originals without disturbing the stack.” — Axi
