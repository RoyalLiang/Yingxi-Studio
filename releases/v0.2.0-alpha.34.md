# 映汐放映室 0.2.0-alpha.34 / Yingxi 0.2.0-alpha.34

## 中文

【拾荒者信笺】

这一回，安装包按设备架构分开打理，放映设备和影像处理照旧。设置页的更新按钮也归回底部，背景铺成同一张纸。

【本次修缮】

1. 安装包按 arm64、armv7、x86_64 与 x86 分发，新版检查更新会选择适合当前设备的包；原有文件名用于 arm64 旧版接续更新。
2. 启用 R8 代码与资源裁剪，保留解码与连接所需的原生入口和反射注册，不更改影片分辨率、码率或色彩处理。
3. 绘画与图像资源改为无损 WebP，保留尺寸、透明度和原像素。
4. 检查更新按钮恢复有色填充并固定在页面底部，移除独立底色和分隔条，正文继续独立滚动。

> 垫圈按尺寸串在细铁丝上。合不上，拧得再紧也不会稳。——迟灯

## English

[Scavenger's letter]

The installer packages are now sorted by device architecture. The projection equipment and image processing remain as they were. The update button returns to the bottom of a page with one continuous paper background.

[Repairs this time]

1. Separate installers serve arm64, armv7, x86_64 and x86. The updated client selects a compatible package; the existing filename carries the arm64 package for older clients.
2. R8 removes unused code and resources while preserving native decoder entry points and connection-provider registration. Film resolution, bitrate and color processing are unchanged.
3. Artwork and image assets use lossless WebP, preserving dimensions, transparency and original pixels.
4. Check for updates regains its filled accent and stays at the bottom. The separate background band and divider are removed while the letter scrolls independently.

> Sort the washers on a thin wire by size. Tightening the wrong one will not make it fit. — Chideng
