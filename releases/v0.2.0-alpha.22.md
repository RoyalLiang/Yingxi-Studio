# 映汐放映室 0.2.0-alpha.22 / Yingxi 0.2.0-alpha.22

## 中文

【拾荒者信笺 · 映汐放映站 0.2.0-alpha.22】

迟灯擦了擦放映机的镜片，又给旧片盒留了一条能走通的光路。阿汐在盒盖上添了行小字：先看清片子的底色，再决定用哪盏灯。

【本次修缮】

1. HDR10 与杜比视界播放优先选择兼容的硬件解码器，保留 HDR 色彩和亮度信息；首个解码器无法启动时，继续尝试其他可用解码器。
2. 结合屏幕与硬件解码能力选择原生杜比视界。手机不支持时，自动将带有可读 HDR10 兼容基础层的 Profile 7，以及明确标记 BT.2020/PQ 的 Profile 8 片源交给 HEVC/HDR10 播放。
3. 原生杜比视界解码器启动失败时，同样尝试兼容的 HDR10 基础层。Profile 5、HLG、SDR 和兼容性不明的片源保留原格式，避免套用错误的 HDR10 色彩。

> 灯可以换，片子的底色不能认错。——迟灯

## English

[Scavenger's letter · Yingxi Screening Room 0.2.0-alpha.22]

Chideng cleaned the projector lens and left another working path for the old film boxes. Axi wrote a small note on one lid: read the picture's colors before choosing its lamp.

[Repairs]

1. Prefer compatible hardware decoders for HDR10 and Dolby Vision while retaining HDR color and luminance metadata. Try other available decoders if the first one cannot initialize.
2. Check both display and hardware decoding support before choosing native Dolby Vision. On unsupported phones, automatically play readable HDR10-compatible Profile 7 base layers and explicitly tagged BT.2020/PQ Profile 8 base layers through HEVC/HDR10.
3. Also try a compatible HDR10 base layer when the native Dolby Vision decoder fails to initialize. Keep Profile 5, HLG, SDR and uncertain formats in their original form to avoid applying incorrect HDR10 colors.

> You can change the lamp. You must still read the picture's colors correctly. — Chideng
