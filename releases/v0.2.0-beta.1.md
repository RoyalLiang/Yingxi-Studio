# 映汐放映站 0.2.0-beta.1 / Yingxi 0.2.0-beta.1

## 中文

【拾荒者信笺】

分散在片架上的登记纸，现在可以翻同一本总录。

【修缮记录】

1. 新增「片匣总录」：将选定的本地文件夹、SMB 与 SFTP 目录收录到一起，按片名或信源查找；原有片架入口继续使用。
2. 新增「放映单」：把不同信源的影片排进同一张单子，调整顺序后依次播放；开播核对时跳过无法读取的条目。
3. 新增「行囊备份」：预览并导出片目、放映单、观看进度与短记，恢复前可核对替换范围。不带走账号凭据、文件路径、文件夹授权或封存内容；导出文件为明文，请自行保管。
4. 新增「检修台」：检查影片当前是否可读，保留能够确认的原因，并可前往信源或重新关联文件；无法确定的情况继续标为未知。
5. 影片可修改显示片名；播放时记下时刻，再到片匣档案中补写短记。重新关联文件后，沿用原来的记录。
6. 旧版观看记录与设置迁入新的资料库；迁移保留原始数据与本地快照，恢复失败可保留现有资料。备份中未能匹配的位置需要手动关联。
7. 沿用现有奶油莓粉界面，统一资料库页面的标题与布局，照顾窄屏和大字号阅读。

> 「抄页装进包里，原册还放桌上。」——阿汐

## English

[Scavenger letter]

The slips scattered across the shelves can now be read in one register.

[Repairs]

1. Add the Film Register: index selected local folders, SMB and SFTP directories together, then search by title or source. Existing shelf entries remain available.
2. Add Screening Lists: arrange films from different sources in one ordered list and play them in sequence. Unreadable entries are skipped during the check before playback.
3. Add Satchel Backup: preview and export film records, screening lists, viewing progress and short notes, then review the replacement scope before restoring. Account credentials, file paths, folder permissions and sealed content are excluded. Exported files are plain text; keep them somewhere private.
4. Add the Repair Bench: check whether a film can be read, retain confirmed causes, and open its source or relink the file. Uncertain results remain unknown.
5. Edit a film’s display title, mark a moment during playback and add a short note in its dossier. Relinking a file keeps its existing records.
6. Move older viewing records and settings into the new library while retaining original data and local snapshots. Failed restores preserve existing records. Unmatched locations in a backup need manual relinking.
7. Keep the existing cream-and-berry design, align library titles and layouts, and accommodate narrow screens and larger text.

> “The copied pages go in the bag. The register stays on the table.” — Axi
