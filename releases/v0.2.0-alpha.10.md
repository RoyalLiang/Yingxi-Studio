# 映汐播放器 0.2.0-alpha.10 / Yingxi 0.2.0-alpha.10

## 中文

### 更新内容
- SMB、SFTP、WebDAV 共用稳定的来源弹窗，仅配置内容淡入淡出；保留网盘选择与手动 WebDAV 接入，以及各级系统返回行为。
- 来源操作使用悬浮的毛玻璃与折射 Toast，成功和错误提示自动消失；重复提示重新计时，长错误可在详情中完整查看，等待系统无障碍推荐时长。
- 首页移除来源添加与附近发现区域。来源页聚焦已保存片库、收藏及分组，新建来源中可按需扫描附近设备。

### 验证与限制
- 独立 SDK35、SDK36 模拟器各 23 项回归通过，覆盖同一弹窗窗口实例、转场中点、协议路径重置、Toast 生命周期、长错误详情、来源操作、云盘受控错误和大字体场景的 Android 模拟器回归。
- 核心 JVM 测试 37 项中 34 项通过、3 项外部依赖测试跳过；Python 35 项通过；Android Lint 无错误，保留 38 项既有警告。
- 毛玻璃与液态效果为 Android 原生渲染近似；一加真机的帧率、功耗与实际局域网发现和认证仍需实机验证，不将模拟器证据等同真机能力。
- 延续正式签名、仅安装包与源码的 Release 策略；iOS 继续暂停发布。

## English

### Changes
- Keeps SMB, SFTP and WebDAV in one stable source sheet and crossfades configuration content, including cloud-provider selection and manual WebDAV entry.
- Adds floating frosted, refractive feedback with automatic dismissal, restarted timeouts for repeated messages, accessibility-aware durations and scrollable full error details.
- Removes source creation and nearby discovery from Home. Sources focuses on saved libraries, favorites and groups; nearby scanning is available on demand while creating a source.

### Validation and limitations
- All 23 regressions passed on each of the independently owned SDK35 and SDK36 emulators, exercising dialog-window identity, intermediate transition frames, protocol path resets, feedback lifetime, full errors, source actions, sanitized cloud errors and larger text in Android emulator regressions.
- Core JVM: 34 passed and 3 external-fixture tests skipped out of 37; Python: 35 passed; Android Lint: zero errors and 38 existing warnings.
- Glass and liquid motion are native Android approximations. OnePlus hardware performance, power use, real LAN discovery and authentication remain unverified on physical hardware.
- Retains the production signing identity and installer/source-only releases. iOS publishing remains paused.
