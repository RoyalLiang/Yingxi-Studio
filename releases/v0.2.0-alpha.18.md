# 映汐播放器 0.2.0-alpha.18 / Yingxi 0.2.0-alpha.18

## 中文

【拾荒者信笺 · 映汐放映站 0.2.0-alpha.18】

这次整理放映时的几个小角落：把锁扣收好，让进度贴近海报，也让预览跟得上手指。

【修缮记录】
1. 锁定播放后收起锁按钮，点击画面才显示解锁入口，稍候自动收起；移除按钮底色，让画面少一处遮挡。
2. 移除选集队列底部的排序说明，给片单留出空间。
3. 最近播放的选中边框只围绕海报，片名不再跟着染色；时长与细进度条移入海报底部，以白字和深色透明渐变兼顾明暗封面。
4. 拖动进度时，预览图跟随滑块并避开屏幕边缘，只保留图片。提前预热独立预览会话，细化取帧位置，优先显示缓存中的最新目标，跳过积压位置并拦住过期画面。

【放映站手记】

拾荒者把那枚总挂在幕布边的锁扣收进了口袋；需要时，轻敲一下便能找到。
