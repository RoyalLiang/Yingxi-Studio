# 映汐放映站 0.2.0-beta.6 / Yingxi 0.2.0-beta.6

## 中文

【拾荒者信笺】

迟灯把夜班灯芯拨亮，顺着接线台和片架走完了一遍长线。卡住转轴的几道空等撤掉之后，放映机接续远端片源顺手了不少。

【修缮记录】

1. 理顺远程信源与网盘的连续取帧节奏：SMB 与 SFTP 在确认顺畅读取后扩大单次批量拉取并改用短步等待，WebDAV 与阿里云盘分片缓存改为内存索引与就地读入以减少拷贝，并在读取链路与同目录外挂发现中复用预读会话、提高并发搜索上限；冷启动探测边界以及信源变更、移除和本机目录撤回拦截仍即时生效。
2. 减少持续放映时的重复锁等待、全量内存校验与空转刷新：兼容播放改为流式核验原生组件，在暂停稳态下跳过重复属性解析与无变更刷新，并将播放器进度条、拖动预览及亮度音量浮层收拢为局部更新，避免整屏控件与视频画面跟随高频重绘；网络影片改为仅在拖动进度时按需预热预览帧，不再于开播后争抢带宽。
3. 整理片匣书架与海报缩略图响应：合并放映单计数与重命名、归档等全表查询，为偏好读取与缩略图刷新加上作用域缓存与单键按需通知，减轻片匣搜索、滚动和后台取图时的界面抖动。
4. 对齐配套工具中的应用展示名称与阿里云盘公开授权校验码格式。
5. 片架索引绳、铅封路签与频段抄本添上新近日常：检修页背点浅印、同向留白木签并排外挂、夜班潮痕压角待干，各自仅作站内记录之用，不替未核路线作保。

> “先稳稳量准头一尺，后头的轮轴就不用步步重起。”——迟灯
