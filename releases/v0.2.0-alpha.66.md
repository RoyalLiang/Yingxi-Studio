# 映汐放映站 0.2.0-alpha.66 / Yingxi 0.2.0-alpha.66

## 中文

【拾荒者信笺】

放映前，先把画幅认清。

【修缮记录】

1. 首次打开方向未知的影片时，沿用实际播放流读取宽高和旋转标记，确认方向后再显露播放器布局；不额外发起网络方向探测。
2. 等待时显示粉色信号波动画并保留返回入口，解码与画面输出继续准备。
3. 已确认的方向可在重启后沿用；过期或错误提示由当前视频属性校正，清理缩略图时一并移除。
4. 修复 90°／270° 旋转标记在方向预判中丢失的问题，并校正兼容后端的初始画幅与像素比例。

5. 画质选择统一为整行选项；字幕页移除资源匹配提示，音轨页移除底部说明，保留手动载入与自定义字幕驿站。
6. 检修弹窗移除原始记录预览和复制按钮；公开问题正文改为诊断表格。等待与完成使用无底板动画，不再闪现阶段文字。

「先认清纸上的朝向，再挂到绳上，风来时就不必翻两回。」——阿汐
