# 映汐放映站 0.2.0-alpha.56 / Yingxi 0.2.0-alpha.56

## 中文

- 站务把检查更新的动静留在原按钮里；守夜人模式与「听音频段」同行排齐，窄屏和大字号也能展开选择。
- 海报与播放片段共用「回收缓存」，回收进度留在按钮内；开屏光影更轻快，并添上当前信笺版号。
- 片窗会主动读取云盘已有的画质档位，也可选择片源实际提供的多档画面；只有原片的片架会如实标明。
- SDR 兼容放映把重复检修移到幕后，减少界面等待；拖动进度后，旧的片尾记录不再打断新的放映。
- 播放检修换成玻璃回执，可先预览或复制快照，再自行决定是否前往网页上报；公开范围与同意选项放在寄出之前，放映恢复也不会收走已经打开的回执。

> 折角不是回信，只提醒我：这张纸还没有寄出。——阿汐
