# 映汐放映站 0.2.0-alpha.54 / Yingxi 0.2.0-alpha.54

## 中文

- 放映站为设备无法解码的 Dolby Vision P5 影像接好 SDR 兼容光路，保留杜比画面重塑信息，映射为正常色彩；原片与分辨率仍留在原处。
- 局域网片源也能沿这条光路放映，继续使用原有的跳转、续播、倍速与字幕控件；设备能正常解码的影片仍沿用原来的播放路径。
- 检修记录会标出 SDR 兼容解码器与首帧，便于辨认画面是否真正开始放映。

> 留白的票根收回铜尺下面，原片罐上的标记一笔也没改。——阿汐

## English

- At the projection station, an SDR compatibility path now opens Dolby Vision P5 video the device cannot decode. Dolby reshaping information is retained for proper colour mapping; the original file and resolution stay in place.
- Local-network sources use the same path with the existing seeking, resume, speed and subtitle controls. Films the device can decode continue on their original playback path.
- Repair records identify the SDR compatibility decoder and first frame, helping distinguish a running clock from an actual picture.

> The blank ticket goes back beneath the brass ruler. Every mark on the original film tin stays untouched. — Axi
