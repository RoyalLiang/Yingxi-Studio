# 映汐放映室 0.2.0-alpha.26 / Yingxi 0.2.0-alpha.26

## 中文

【拾荒者信笺】

放映站翻开日记，把今天新见到的影像逐一登记。片架按季集归好，幕布边留了一句短话，路标也擦掉了多余的一行字。

【本次修缮】

1. 首页加入拾荒者日记、每日短句和低频问候；浏览本机或远程目录时登记新发现的影片，汇入「今日拾获」。
2. 本机文件入口改为「废墟档案库」，增加电影、剧集、综艺筛选与季集摘要，可继续上次那一集的断点，原文件名依旧清楚可见。
3. WebDAV 连接页换上「外部避难所」路标，保留真实协议、地址和认证字段。
4. 播放等待时，胶片与信号标识连同「信号破译中」居中显示；紧凑的短气泡从右侧出现，恢复播放后收起。快进、快退轻提示音可选，默认关闭。
5. 没有内嵌字幕时，优先匹配同目录同名的 SRT、ASS、SSA、VTT，再查找在线字幕；增加音轨语言偏好和手动语言选择记忆开关。

> 这批影像登记好了，片架给你留了位置。——阿汐
