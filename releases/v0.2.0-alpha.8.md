# 映汐播放器 0.2.0-alpha.8 / Yingxi 0.2.0-alpha.8

## 中文

### 更新内容

- Release 仅保留安装包与 GitHub 自动生成的源码压缩包；审计、校验、依赖和截图附件保留在 CI 与本地记录。
- 应用内更新改为读取 GitHub APK 资产的版本、大小和 SHA-256，不再依赖独立 JSON 附件；仍严格校验包名、版本和当前应用签名。
- 暂停后续 iOS 自动发布，保留手动构建流程。阿里云盘错误提示增加失败阶段、允许显示的官方错误码与请求编号，隐藏响应原文及授权凭据。
- Android PKCE challenge 保留官方 SDK 使用的 Base64 末尾补位；强随机 verifier 和 state 不变。该协议兼容性调整仍需真机重新授权验证。

### 验证与限制

- 运行受控的附件保留/备份/删除测试、更新资产解析和下载完整性/取消/签名测试；实际结果以 CI 和交付记录为准。
- 旧版更新检查依赖 JSON，精简附件后可能需要手动下载安装本版本一次；相同正式签名支持覆盖安装并保留本地数据。
- 用户 Android 真机反馈阿里云盘授权 HTTP 400，根因尚待阶段错误码确认；本版增加诊断，尚不宣称真实授权或播放通过。iOS 已发布 alpha.2 保持原有未签名边界，后续发布暂停。

## English

### Changes

- Keeps only installers and GitHub-generated source archives on Releases; audit data, checksums, dependency lists and screenshots remain in CI/local records.
- Uses GitHub APK asset versions, sizes and SHA-256 digests for in-app updates, while retaining strict package, version and installed-certificate verification.
- Pauses automatic iOS publication and retains manual builds. Aliyunpan errors identify the operation, allowlisted provider error code and request ID without exposing raw responses or authorization credentials.
- Retains Base64 padding on the Android PKCE challenge to match the first-party mobile SDKs, while keeping independently generated secure verifier/state strings. Physical-device reauthorization remains required to validate this compatibility adjustment.

### Validation and limitations

- Controlled tests cover asset retention, backup-before-delete, update parsing, download integrity, cancellation and signing identity. CI and delivery evidence record actual results.
- Older clients rely on the removed JSON attachment and may require one manual installation of this version. The established release signing identity is retained for in-place upgrades.
- A physical Android device reported HTTP 400 during Aliyunpan authorization; the cause still requires operation-specific diagnostics. This build adds diagnostics and does not claim verified real authorization/playback. The published iOS alpha.2 remains unsigned; further iOS publication is paused.
