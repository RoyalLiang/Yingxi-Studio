# 映汐放映站 0.2.0-beta.3 / Yingxi 0.2.0-beta.3

## 中文

【拾荒者信笺】

检修纸上的旧回执收回抽屉，新的动静留给眼前这一场放映。

【修缮记录】

1. 打开设置时不再重复弹出旧的取消安装提示；已下载的安装包仍可手动继续安装，不会因重进设置再次打开系统安装界面。
2. 上报播放问题时收起画面下方的加载圈，避免与上报动效叠在一起；关闭上报后按实际播放状态恢复显示。
3. 播放检修回执补记片壳提示、容器解析阶段、读取位置及跳转次数，帮助追查开场与续播的停顿；片名、路径和账号仍留在本机。
> 「给下一次检修留一点余量。」——迟灯

## English

[Scavenger letter]

Old repair receipts return to the drawer, leaving the next signal to the screening in front of us.

[Repairs]

1. Opening Settings no longer repeats an old installation cancellation. Downloaded updates remain available for manual installation without reopening the system installer on entry.
2. Hide the playback loading ring while a problem report is open so it cannot overlap the reporting animation. Restore it on dismissal when playback still needs it.
3. Add container hints, extraction phases, byte positions and seek counts to playback reports to help trace startup and resume stalls. Film names, paths and accounts stay on the device.
> “Leave a little slack for the next repair.” — Chideng
