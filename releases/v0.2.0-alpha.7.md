# 映汐播放器 0.2.0-alpha.7 / Yingxi 0.2.0-alpha.7

## 中文

### 更新内容

- 接入阿里云盘公开客户端 PKCE：通过官方 App 登录授权，验证账户与默认盘后添加来源；缺少 App 时提供安装提示。
- 支持只读目录分页、文件夹优先的名称自然排序、视频播放与稳定文件标识续播；API 令牌不会发送到视频 CDN，临时链接过期可重新解析一次。
- 凭据使用 Keystore 加密；移除账户使旧授权与刷新结果失效。加强播放取消、并发凭据提交与来源删除的安全边界。

### 验证与限制

- JVM 33 项中 30 项通过、3 项外部环境测试跳过；脚本 26 项通过；Android 15/16 模拟器对同一候选各通过 13 项回归；Lint 0 错误、40 警告。受控测试覆盖 PKCE、分页、自然排序、Range、链接失效、取消和凭据删除竞态。
- 注册 AppID 的官方授权入口已返回有效原生跳转地址；真实账户授权、目录和网盘视频仍待用户真机联调，不属于受控测试已通过的范围。


- 需安装阿里云盘官方 App；平台审核、普通应用配额、连接和编码能力仍受实际环境约束。公开客户端刷新失败时需重新授权。
- 百度正式接入未启用，手动 WebDAV、SMB、SFTP 继续可用。移除本地账户不等同在平台撤销授权，可在官方授权管理中撤销。
- iOS 另行提供 ios-v0.1.0-alpha.2；未签名 IPA 需自行签名，不能直接安装。

## English

### Changes

- Adds Aliyunpan public-client PKCE login through the official app, verified account/default-drive sources, paginated read-only browsing and natural episode ordering.
- Supports stable file-ID history and ranged video playback. API bearer tokens stay at the API origin; expired CDN URLs can be resolved once again.
- Encrypts credentials with Android Keystore and prevents cancelled or removed accounts from returning through late authorization/refresh results.

### Validation and limitations

- JVM: 30 passed, 3 external-environment tests skipped. Python: 26 passed. The same candidate passed 13 targeted tests on each Android 15/16 emulator; lint reported 0 errors and 40 warnings. Tests cover PKCE, pagination, ordering, ranges, expiry, cancellation and credential-deletion races. The registered public authorization entry returns a valid native redirect; real-account consent, cloud browsing and video playback still require user-assisted physical-device validation. Provider quotas and codecs apply; refresh failures require sign-in again. Baidu OAuth remains unavailable. Local removal does not revoke the grant at the provider. The separate iOS alpha remains unsigned.
