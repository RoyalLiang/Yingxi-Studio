# 映汐放映室 0.2.0-alpha.24 / Yingxi 0.2.0-alpha.24

## 中文

【拾荒者信笺 · 映汐放映室 0.2.0-alpha.24】

阿汐在柜台摊开一本日记，把今天新见到的影像逐一登记。迟灯把一句话留在幕布右边，等放映机歇口气时再递过来；弥途则擦掉了路标上多余的一行字。

【本次修缮】
1. 首页加入拾荒者日记、每日短句和低频问候；浏览本机或远程目录时登记新发现的影片，汇入「今日拾获」。
2. 本机文件入口改为「废墟档案库」，增加电影、剧集、综艺筛选与季集摘要，可继续上次那一集的断点，原文件名依旧清楚可见。
3. WebDAV 连接页换上「外部避难所」路标和弥途的提醒，保留真实协议、地址和认证字段。
4. 播放等待时，胶片与信号标识连同「信号破译中」居中显示；迟灯的短句从右侧轻轻出现，恢复播放后收起。新增角色问候与可选的快进、快退轻提示音设置，音效默认关闭。
5. 自动字幕优先查找同目录同名的 SRT、ASS、SSA、VTT，再查找在线字幕；增加音轨语言偏好和手动语言选择记忆开关。

> 这批影像登记好了，片架给你留了位置。——阿汐
