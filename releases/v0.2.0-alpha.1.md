# 映汐 0.2.0-alpha.1 / Yingxi 0.2.0-alpha.1

## 中文

### 更新内容

- 首个 Android 本地与局域网播放器验证基线，面向 Android 15/16 手机。
- 支持选择本机媒体，以及 SMB/SFTP 来源发现、认证与目录浏览；发现候选不等于已认证可读来源。
- 提供远程媒体随机定位与沉浸式播放，随安装包附带第三方声明、依赖清单和完整性校验。

### 验证与限制

- 自动发布要求源码检查、Python/JVM 测试、APK 构建和 Lint 通过；Release 资产记录源码提交、安装序号、签名指纹和 SHA256。
- 本版本属于预发布验证阶段，自动检查不等于目标真机、现场 NAS、无线网络或高码率样片验收。
- 正式发布签名与此前本地 debug 签名不同，可能需要卸载后安装；卸载会清除本地来源、文件授权和历史记录。

## English

### Changes

- Establishes the first Android local and LAN media player validation baseline for Android 15/16 phones.
- Supports local media selection and SMB/SFTP discovery, authentication and directory browsing. Discovered candidates remain distinct from authenticated, readable sources.
- Provides random-access remote playback and immersive viewing, with third-party notices, a dependency inventory and integrity checks alongside the APK.

### Validation and limitations

- Automatic publication requires source checks, Python/JVM tests, APK builds and Lint to pass. Release assets record the source commit, version code, signing fingerprint and SHA256.
- This is a prerelease validation build. Automated checks do not establish acceptance on the target phone, field NAS, wireless networks or high-bitrate samples.
- The release signing identity differs from earlier local debug builds and may require uninstalling first. Uninstalling removes saved sources, file grants and playback history.
