# 映汐放映室 0.2.0-alpha.29 / Yingxi 0.2.0-alpha.29

## 中文

[拾荒者信笺]

片架旁多了一条去远处的路。下载的胶片也能留住断点，灯暂时暗下来，回来接着搬。

[本次修缮]

1. 检查更新、下载和安装操作固定在页面底部，移除“本版说明”标题，补齐更多菜单的按压与悬浮反馈。
2. 放映设置统一开关的颜色和状态，底部新增“探索”，可阅读现有来信、地点图谱与据点大事记。
3. 登记气泡收拢到页面下方，只在添加避难所或本机目录后出现；日常进入文件夹不再反复提醒。
4. 目录路径可点击返回上层与根目录，默认进入目录不再挡住重新定位。
5. 更新下载保留断点，切换应用或熄屏时由后台任务接续；失败后可继续下载，安装前仍核对完整性和签名。
6. 放映室门牌保持同行，打开影片先进入横屏并按比例铺满，仍可切回完整画面。避难所入口与值班札记统一用语和材质。

> 线接好了。歇会儿也成，回来接着放。——迟灯
