# 映汐播放器 0.2.0-alpha.9 / Yingxi 0.2.0-alpha.9

## 中文

### 更新内容

- 修复阿里云盘目录中合法空值的大小、创建时间，以及账户空名称导致的读取异常。
- 目录打开与历史续播保留受控的网盘操作阶段、官方错误码与请求编号；未知网络异常原文不进入提示，避免暴露凭据。
- 新授权账户切回全部来源分组；首次目录加载失败时仍可找到已保存的账户重试。

### 验证与限制

- 受控连接器复现空字段异常，实际 ViewModel 与界面复现错误被覆盖、历史续播原文显示和来源分组隐藏；修复后重新执行对应回归。
- 用户确认 alpha.8 授权后仍报通用连接或读取失败，且更正为未看到新来源；本次修复已确认的解析与反馈缺陷，不宣称真实授权、目录或播放已通过，仍需真机复测。
- 延续正式签名、仅安装包与源码的 Release 策略；iOS 继续暂停发布。

## English

### Changes

- Accepts nullable size and creation-time metadata in Aliyunpan directories and nullable account display names.
- Preserves sanitized operation, provider code and request ID during directory opening and history replay; hides arbitrary transport exception messages.
- Shows newly authorized accounts in all sources so an initial directory failure does not hide the saved account behind a group filter.

### Validation and limitations

- Controlled connector tests reproduce nullable-field failures. Actual ViewModel and UI tests reproduce overwritten diagnostics, raw history-replay errors and hidden newly authorized accounts, then repeat the same checks after correction.
- The user confirmed alpha.8 still reports a generic connection/read failure and corrected their report to no new source visible. This build addresses verified parser and feedback defects; real authorization, directory access and playback remain pending physical-device validation.
- Retains the established signing identity and installer/source-only Release policy. Further iOS publication remains paused.
