# 映汐放映站 0.2.0-alpha.49 / Yingxi 0.2.0-alpha.49

## 中文

【拾荒者信笺】
桌上添了一只调谐旋钮。线条靠近，杂讯渐淡，一张旧短笺便留在眼前。

【本次实装】
1. 探索新增「调频寻声」：六段双语离线练习，转动旋钮或点步进键，让实线靠近虚线；刻度、距离与文字一起指路。
2. 短笺随时可以直接读，也能查看提示、重调本段或换段，并从短笺打开档案。离开再回来，刻度与阅读状态继续保留。
3. 可选微弱合成底噪默认关闭，随信号接近渐轻；对准、播放切换、后台或离开时停声。
4. 两项探索练习共用一组入口，与原有章节、图谱保持相同的纸面留白和按钮样式。

> 我把旋钮旁的刻线补深了一点。听不见也没关系，纸上的两条线靠在一起，手就知道该停了。——迟灯
