# 映汐放映站 0.2.0-beta.7 / Yingxi 0.2.0-beta.7

## 中文

【拾荒者信笺】

迟灯把半张旧检修纸垫在抄本下。阿汐清净夹口，把几张尚未归好的纸签重新对齐。

【修缮记录】

1. 浏览、搜索和打开片匣档案时，重新核验本机文件的封存范围，避免文件目录归属改变后仍沿用旧的可见性结果。
2. 移除拾荒记录后，让其他尚在准备的缩略图重新接续，修正卡片一直空白的问题。
3. 收起片匣时在后台完成数据库收尾，避免退出被加载中的查询拖住。
4. 频段抄本添一则垫纸晾页短笺：旧编号留在原页，垫纸上的潮痕不算新读数。

> “等纸干了，再把夹子归回原位。”——迟灯

## English

[Scavenger letter]

Chideng slips half an old repair sheet beneath the logbook. Axi clears the clip and straightens the slips still waiting to be filed.

[Repairs]

1. Recheck sealed-folder boundaries when browsing, searching or opening catalog details, so a change in a local file’s folder relationship does not retain an old public listing.
2. Let other pending thumbnails resume after a history entry is removed, fixing cards that could remain blank.
3. Finish database cleanup in the background when leaving the catalog, keeping an ongoing query from holding up the exit.
4. Add a logbook note about drying a page over scrap paper. Old numbers stay on their original page; damp marks on the backing are not new readings.

> “Let the page dry, then return the clip.” — Chideng
