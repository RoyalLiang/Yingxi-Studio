# 映汐放映室 0.2.0-alpha.21 / Yingxi 0.2.0-alpha.21

## 中文

【拾荒者信笺 · 映汐放映室 0.2.0-alpha.21】

阿汐把新名牌钉到门楣上，退后两步，才发现档案室的指示牌还藏在柜台后面。迟灯端着冷茶笑她，弥途已经把画着红铅笔的肖像挂到了门边。

【本次实装】
1. 应用更名为「映汐放映室」。首页直接展示档案室入口，版本页也保留通路。
2. 阿汐、迟灯、弥途换上各自的原创肖像：旧护目镜与胶片盘、铜线耳机与放映灯、红铅笔与罗盘。档案里先见人物，再沿图谱读远方。

【修缮记录】
3. 海报持久保存在本地，打开影片卡片时先显示已有图片。后台定期核对匹配信息，只接纳高置信度结果；更新失败时保留旧海报，图片与来源记录一起保存。
4. 「剧名/1、2、3」这样的剧集和综艺改用目录片名查找海报，也会识别季目录；保留有明确片名的电影，避免混合目录串图。
5. 电影卡片的三个点继续靠近海报右上角，点击范围仍保留。
6. 为缺少 Profile 7 原生支持的设备增加可识别 HEVC Main10 基础层回退，按 HDR10 播放；设备支持时保留原生杜比视界。

【放映站手记】
> 先别说它坏了。给我一盏灯。——阿汐

迟灯把一张旧海报压平，留在片架上。下次推门时，就不用等海风再送它来一遍。
